## 提示词怎么写

一条好用的提示词基本是这几块拼起来的：**画面主体 + 细节 + 构图 + 风格 / 光线 + 画面里的文字**。

- 要出中文字（海报标题、包装文案），把字写进引号里，并说清放在哪、什么字体，比如：顶部居中写「夏日限定」四个字，粗黑体
- 写清画幅：竖版 3:4 适合小红书，1:1 适合电商主图，16:9 适合封面
- 改自己的图（换背景、换装、修图）时上传参考图，提示词里写「保持人物 / 产品不变」，再写要改什么
- 详细写法见 [提示词教程](https://pixelark.art/guides)
